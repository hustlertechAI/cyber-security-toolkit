# Cyber Security Toolkit

Cyber Security Toolkit is a beginner-friendly open-source project that provides simple tools for learning and practicing basic cyber security concepts.

## Features

- Password strength checker
- Secure password generator
- Hash generator
- Basic port scanner
- Security tips for beginners

## Purpose

This project is designed to help beginners understand practical cyber security tools and improve their technical skills through open-source development.
